Discovery Plugins Admin

A new view in the admin panel, under Discovery: which plug-ins act on a Discover recommendation, who may start the jobs they run, what is sitting in Discover downloads, and what happened to the last hundred jobs. Drawn in the admin panel’s own look, read off the running app. Each card is a live page; open it at full size to read the notes.

builtthe whole API under it: the switch, the job gate and its per-user flag, the retention pass, the all-users jobs list (PR #1005), plus one status route, plug-in settings, a dry-run probe and the downloads clock (branch feat/discovery-plugins-admin)
buildingthe view itself (webapp/admin), on the same branch
plannedtwo row shapes drawn only to prove the row holds them: a webhook that needs setup, ListenBrainz with a connected count

Decided · 18 Sep

  1. The view sits under Config, directly below Discovery.
  2. One card with four tabs: Plug-ins, Jobs, Downloads, Activity.
  3. No “what leaves the server” line on the rows. Revision 1 drew one; it is gone from the cards, the API and the registry.
  4. Defaults stay as they are: the preview plug-ins ship switched on, YouTube ships off.
  5. Discover downloads gets a size cap: 5 GB by default, 0 for none, checked before each download (card 05).

Still assumed

  1. Every control applies at once with a toast; no APPLY button on the access radios, unlike Torrent’s “Enabled For”.

The API under the view

  1. built GET /api/v1/admin/discovery-plugins/status: one answer for the header, the plug-in list with settings values, the job gate and the downloads numbers.
  2. built plug-in settings on the existing switch route, validated by each plug-in’s config schema, applied live.
  3. built POST /api/v1/admin/discovery-plugins/probe: “check again” and the modal’s Test, a dry run with unsaved values that also drops the probe cache.
  4. built small additions: downloadsRetentionDays and downloadsMaxSizeMb (the size cap) on the jobs setter, allowDiscoveryJobs in the users list, username on the admin jobs list, editable settings and probe detail in the registry.
  5. built the switch, the gate, the per-user flag, Sweep now, the all-users jobs list and cancel.
