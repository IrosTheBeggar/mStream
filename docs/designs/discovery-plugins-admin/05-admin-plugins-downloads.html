Downloads tab — what the plug-ins brought in

A Get it download and a copy from a paired server both land in the user’s own collection folder, like any upload, and leave a record of where the file came from (plugin_downloads, V75). There is no scratch folder, no clock and no cap: a download is a library song from the moment it lands, and the user’s own Downloads panel lists and removes it. This tab is the operator’s view of the same records across every account — counted by plug-in, listed newest first, with [remove] for any of them. The classic Youtube DL upload writes the same record, so it shows here too.

Rules

The tiles come from the status route: GET /api/v1/admin/discovery-plugins/status → downloads[] { plugin, count, bytes }, live records only (removed ones are history), one entry per plug-in; the two totals add them up. The list is the user’s own route with the admin switch: GET /api/v1/discovery/downloads?all=1&limit=200 (+ removed=1 for the history), each record with its username — the shared anonymous account of a server with no users stays nameless — and present, which follows the library row: a scan that loses the file, or a file deleted by hand, makes a row missing without touching the record.

[remove] is the same route the user has, DELETE /api/v1/discovery/downloads/:id, open to admins for any account: it deletes the file (EBUSY answers 409 “in use”), the library row and any playlist entry on it, then settles the record (removed_at, removed_by). A missing file settles the record alone. It asks once and names the owner, like [cancel] on the Activity tab.

Nothing is set here. No clock, no cap, no folder: the only download-related config key left is discoveryJobs.stagingDir (where a download is assembled before it enters a library), a config-file key with no row; the Jobs tab’s Sweep now removes staging folders a crash left behind.

Words come from the player: the admin page loads webapp/alpha/discover-jobs.js and draws each row through downloadRow, the same function behind the user’s Downloads panel, so “file missing” means the same thing on both.
